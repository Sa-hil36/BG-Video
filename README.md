# Background Video Landing Page

A simple landing page with a full-screen background video and overlayed content.

## Features
- Full-screen background video that automatically plays, loops, and is muted.
- Overlay content section with a headline and a call-to-action link.
- Responsive design (via `meta viewport`).

## Technologies Used
- **HTML5** — structure
- **CSS3** — styling and layout
- **Video file** — `video.mp4` used as background
